# **B. Banyak Jalan Menuju Exit**

time limit per test: 1 second\
memory limit per test: 64 megabytes

### **Deskripsi**

Anda sedang terjebak di sebuah _maze_ yang untungnya, tidak terlalu besar. _Maze_ ini berbentuk persegi panjang berukuran N\*M, dan terdiri dari petak-petak berukuran 1\*1. Sehingga, terdapat N baris dan M kolom di maze ini. Pojok kiri atas berada di petak (1,1), sedangkan kanan bawah berada di petak (N,M). _Maze_ ini cukup aneh, karena di dalam _maze_ ini, anda hanya dapat berpindah ke petak yang berada tepat di kanan atau tepat di bawah (tentunya jika petak itu ada!). Saat ini, anda berada di pintu masuk, alias petak (1,1). Pintu keluar berada di petak (N,M). Tentukan, ada berapa cara berbeda anda bisa mencapai pintu keluar?

### **Format Masukan**

Satu baris berisi 2 buah bilangan bulat N dan M, yang menyatakan ukuran _maze_.

### **Format Keluaran**

Satu baris berisi sebuah bilangan bulat, banyak cara mencapai pintu keluar.

### **Contoh 1**

###### **Masukan**

```
3 2
```

###### **Keluaran**

```
3
```

### **Batasan**

- $1\le N, M\le 10$
